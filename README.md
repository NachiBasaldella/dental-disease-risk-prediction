Dental Disease Risk Prediction Using Machine Learning
Bachelor's Thesis | Data Science | Universitat Carlemany

This project investigates how machine learning can help predict dental disease risk using socioeconomic variables and oral health habits.

Dataset: NHANES (National Health and Nutrition Examination Survey).

Machine Learning Models:
- Logistic Regression
- Random Forest
Evaluation: Accuracy, Precision, Recall, F1-score and ROC-AUC.

Author: Nazaret Basaldella
